## 1. 为什么要重排

现行 CD-61 按「M0 底座 → M3 联机 → M4 规则+发布 → M5 切片验收 → M6/M7 BASTION」写。纠偏已经证明三件事：

1. **导出与真网络是参数决策的前置条件**，不该埋在 M5；
2. **M4 把 L2 Rule VM 与 L6 内容平台捆在同一号**，粒度不可比；
3. [CD-11 §4](../../Confirmed-docs/10-product/11-scope-and-platforms.md#4-一期必须完成) 有三条必做纵向线在 CD-61 **没有所有者**：表现/美术、平台导出与 Web、账号 + 草稿云 + 内容平台。

纠偏冻结令（C0–C5）是临时闸门，不是新的里程碑编号。解冻后仍要回到 CD-61，所以必须先把所有者补齐。

现行：「客户端不能伪造位置、冲线、道具和障碍破坏；离线结果没有在线写入。」
