## 怎么用

1. 检出待审 PR 的分支（不要用过期的 `main` 冒充本章）。
2. 先做下面「共用启动」（本刀写了「不需要三后端」则可跳过 `npm run dev`）。
3. 只做 **本刀** 的编号步骤。每步有「预期」和「失败」。全部预期满足才勾 PR 里的真机项。
4. 合入后本刀会被下一章替换；历史步骤以该章 PR 正文为准。

## 共用启动（大厅窗口）

机关狂奔匹配大厅是代码创建的 `Window`，标题 **Traprush**。第一行是状态 Label。按钮（从左到右）：**Quick play**、**Create room**、**Join room**、**Solo play**、**Cancel**、**Poll**。其下三个输入框：房间码（placeholder `Room code`）、课程 id（默认 `course_01`）、人数（默认 `2`）。窗口里的 3D：蓝色 1 米盒是玩家；橙色盒是可破坏箱；垫 / 门 / 终点是赛道占位盒；条是传送连线与检查点顺序 gizmos。玩家盒上方有名次 Label。

### 0.1 后端（本刀需要在线入场时）

仓库根目录：

```bash
npm run dev
```

预期：控制面、网关、MatchHost 三个 `/readyz` 都就绪后 DevLauncher 才放行。不要在半就绪时开游戏。停：对该终端 Ctrl+C。

Worktree 端口偏移见 README「并行工作区」；本文件不复述端口号。

### 0.2 打开窗口化主场景

**不要**用 Headless `--quit`。

| 平台 | 命令（仓库根） |
|---|---|
| Windows | `& $env:GODOT4 --path game` |
| macOS | `"$GODOT4" --path game` |

也可以先 `& $env:GODOT4 --editor --path game` / `"$GODOT4" --editor --path game`，再在编辑器里运行主场景。

预期：出现标题为 **Traprush** 的窗口；状态行含 `join=idle`、`play=idle`、`course=3/2/1`（默认 `course_01` 的垫/门/终点占位）。失败：没有窗口、立刻退出、或只有 Headless 日志。

操作：WASD 移动，空格跳跃，R 重置到检查点。点窗口内部一次，确保键盘焦点在游戏窗口而不是终端。

## 本刀：对局本席移动预测

对应：当前完整章节 PR。锁的是**本席 Move/Jump 的表现 overlay**，不是远端外推，也不是平滑对账。

先做 A（Solo 不叠 overlay），再做 B（在线立即动）。B 才是本章主路径。

### A. 离线 Solo（本地权威，不要双倍位移）

不需要 `npm run dev`。若已在线对局，先点 **Cancel** 回到 `play=idle`。

1. 课程框保持 `course_01`。点 **Solo play**。
2. 看状态行。

   预期：出现 `offline=playing`、`离线试玩，成绩不上传`、`play` 不是 `in_match`、`players=1`、`mapped=1`，并有一个蓝色玩家盒。失败：发起了 HTTP，或没有玩家盒。

3. 点窗口内部。轻推 **D**（或 WASD）一小段。

   预期：蓝色盒按本地权威移动，速度与上一章 Solo 相当，**不会**突然加倍。失败：每一下键盒跳出去特别远（叠了预测 overlay）。

4. 点 **Cancel**。

   预期：`offline=` 不再是 `playing`，蓝色玩家盒消失，WASD 不再移动任何玩家盒。失败：点了之后还能继续走。

点 **Cancel** 结束后再做 B。

### B. 快速游戏（本席立即动、权威硬贴）

需要「共用启动」0.1 与 0.2。人数改成 `1`，这样不必等第二人。

1. 课程框 `course_01`，人数框改成 `1`。点 **Quick play**。
2. 等状态行出现 `join=ready`、`play=in_match`、`seats=1`、`seat=0`、`mapped=1`，蓝色玩家盒出现。若长时间停在 `connecting` 或 `error=`，先看 `npm run dev` 三个进程是否仍在。

3. 点窗口内部。在平地上 **轻点 WASD**（不要冲进传送门），看蓝色玩家盒和盒上方名次 Label。

   预期：按下的瞬间盒就动，不必等快照拍子；名次 Label 跟着本席盒走。失败：按了键要明显顿一拍才动。

4. 走进传送门，或按 **R**。

   预期：蓝色盒**立刻跳**到新格（传送 / 重置不预测；任一轴 ≥ 1 表现米格子则贴最新）。失败：传送 / 重置时盒在空中滑过去。

5. 再看橙色箱子和赛道垫。

   预期：仍停在原位，不跟本席 overlay 移动。失败：箱子跟着滑。

6. 点 **Cancel** 停场（不要点窗口关闭，见共用启动说明：Traprush 是嵌入子窗口，关闭只是隐藏）。

   预期：状态行变为 `join=idle` `play=idle`，不再出现 `tick=`；蓝色玩家盒与名次 Label 消失；WASD 不再让盒移动。失败：点了之后 `tick=` 仍在涨，或还能继续走。

### 本刀不测

- 远端外推、平滑对账、本地碰撞预测；
- 产品插值窗口、Tick Hz、快照频率、跳跃高度（对局进程 jump_dy 仍为 0）；
- 第二人同屏、账号绑定。
