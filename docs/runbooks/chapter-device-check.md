## 怎么用

1. 检出待审 PR 的分支（不要用过期的 `main` 冒充本章）。

## 共用启动（大厅窗口）

机关狂奔匹配大厅是代码创建的 `Window`，标题 **Traprush**。第一行是状态 Label。按钮（从左到右）：**Quick play**、**Create room**、**Join room**、**Solo play**、**Cancel**、**Poll**。其下三个输入框：房间码（placeholder `Room code`）、课程 id（默认 `course_01`）、人数（默认 `2`）。窗口里的 3D：蓝色 1 米盒是玩家；橙色盒是可破坏箱；垫 / 门 / 终点是赛道占位盒；条是传送连线与检查点顺序 gizmos。玩家盒上方有名次 Label。

### 0.1 后端（本刀需要在线入场时）

仓库根目录：

```bash
npm run dev
```

预期：控制面、网关、MatchHost 三个 `/readyz` 都就绪后 DevLauncher 才放行。不要在半就绪时开游戏。停：对该终端 Ctrl+C。

Worktree 端口偏移见 README「并行工作区」；本文件不复述端口号。

### 0.2 打开窗口化主场景

**不要**用 Headless `--quit`。

| 平台 | 命令（仓库根） |
|---|---|
| Windows | `& $env:GODOT4 --path game` |
| macOS | `"$GODOT4" --path game` |

也可以先 `& $env:GODOT4 --editor --path game` / `"$GODOT4" --editor --path game`，再在编辑器里运行主场景。

预期：出现标题为 **Traprush** 的窗口；状态行含 `join=idle`、`play=idle`、`course=3/2/1`（默认 `course_01` 的垫/门/终点占位）。失败：没有窗口、立刻退出、或只有 Headless 日志。

操作：WASD 移动，空格跳跃，R 重置到检查点。点窗口内部一次，确保键盘焦点在游戏窗口而不是终端。

## 本刀：对局快照插值

对应：[PR #140](https://github.com/czmomocha/craftarena/pull/140)。锁的是相邻权威快照之间的**表现采样**，不是预测，也不锁插值窗口 / Tick / 快照频率。

先做 A，再做 B。A 不证明「亚格子滑动」；B 才是插值主路径。

### A. 离线 Solo（贴最新、赛道不跟滑）

不需要 `npm run dev`。若已在线对局，先点 **Cancel** 回到 `play=idle`。

1. 课程框保持 `course_01`。点 **Solo play**。
2. 看状态行。

   预期：出现 `offline=playing`、`离线试玩，成绩不上传`、`play` 不是 `in_match`、`players=1`、`mapped=1`，并有一个蓝色玩家盒。失败：发起了 HTTP（本步不应拉匹配）、没有横幅、或没有玩家盒。

3. **不要点窗口关闭。** Traprush 是嵌入子窗口，关闭只是隐藏，当前没有「再打开」按钮；误关后只能结束 Godot 进程，从 0.2 重开。隐藏期间不推进插值由 GUT `test_sub_cell_snapshot_interpolates_and_hidden_window_does_not_advance` 覆盖，本步不在真机复做。

4. 窗口可见时按 **R**（重置）。

   预期：蓝色盒**立刻跳**到检查点附近，不在空中滑过去。失败：盒拖着一条轨迹滑回出生点。

5. WASD 走进一道传送门占位盒。

   预期：蓝色盒**立刻跳**到对面门，不穿过世界滑过去。失败：盒在两点之间平滑飞过去。

6. 走动时看橙色箱子、垫、门、连线、顺序标。

   预期：这些东西停在赛道拓扑位置，不跟着玩家盒插值移动。失败：箱子或垫跟着玩家滑。

说明：Solo 里每次按键编码常常是**同一 tick 替换快照**，不会建立 previous，所以 WASD 小步看起来会**贴最新**，这是实现如此，不是失败。亚格子滑动放到 B。

点 **Cancel** 结束离线后再做 B。

### B. 快速游戏（亚格子滑动）

需要「共用启动」0.1 与 0.2。人数改成 `1`，这样不必等第二人。

1. 课程框 `course_01`，人数框改成 `1`。点 **Quick play**。
2. 等状态行出现 `join=ready`、`play=in_match`、`seats=1`、`mapped=1`，蓝色玩家盒出现。若长时间停在 `connecting` 或 `error=`，先看 `npm run dev` 三个进程是否仍在。

3. 点窗口内部。在平地上 **轻推 WASD**（不要冲进传送门），看蓝色玩家盒和盒上方名次 Label。

   预期：盒在两次快照更新之间**滑动**，而不是每拍瞬移一格；名次 Label 跟着盒走，进度数字仍跟最新权威（不会在滑动中倒退）。失败：小步移动时盒一格一格蹦；Label 留在旧位置。

4. 走进传送门，或按 **R**。

   预期：蓝色盒**立刻跳**到新格（任一轴 ≥ 1 表现米格子则贴最新）。失败：传送 / 重置时盒在空中滑过去。

5. 再看橙色箱子和赛道垫。

   预期：仍停在原位，不跟玩家插值。失败：箱子跟着滑。

6. 结束时点 **Cancel**，不要点窗口关闭（见 A.3）。

### 本刀不测

- 本地移动预测、远端外推、平滑对账；
- 产品插值窗口、Tick Hz、快照频率（均未锁）；
- 第二人同屏、账号绑定、重连补票。
