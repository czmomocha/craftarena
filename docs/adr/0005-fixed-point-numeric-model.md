# ADR-0005 权威定点数的尺度、舍入、溢出与三角函数

- 状态：**已拍板并落地**（2026-08-21 项目负责人整包采纳推荐）
- 日期：2026-08-21
- 相关：[CD-00](../../Confirmed-docs/00-constitution/CONSTITUTION.md) 第五、八、十一条、[CD-42 §1.1](../../Confirmed-docs/40-technical/42-contracts-and-rulevm.md)、[CD-43](../../Confirmed-docs/40-technical/43-networking-and-replay.md)、[CD-63](../../Confirmed-docs/60-plan/63-open-decisions.md)、[CD-91](../../Confirmed-docs/90-reference/91-decision-log.md)

## 背景

M1 阶段 A 要冻结 L0 `SharedContracts`，其中包含「定点数类型与运算」。[CD-42](../../Confirmed-docs/40-technical/42-contracts-and-rulevm.md) 只锁定了「64 位整数承载、有明确尺度与溢出规则」；单位尺度、舍入、溢出检查和三角函数策略在 CD-63 第 1.6 条，**没有默认答案**。

Godot 4.7 GDScript 的 `int` 是 64 位；没有 `int128`，也没有十进制 `Decimal`。权威路径禁止 `float`、禁止 Godot `sin`/`cos`、禁止把 Node 物理当数据库。表现层在 L4 边界才允许转浮点。

Tick 频率仍是 CD-63 第 1.5 条，本 ADR **不锁定** Hz。冷却、无敌、机关周期用 Tick 计数，不把「1 秒」写成定点数。

## 推荐方案（请整包拍板）

建议一次选定下面四项，作为 M1 仿真与回放的数值合同。名称只用于本 ADR，不进代码标识符。

| 项 | 推荐 |
|---|---|
| 空间尺度 | **65 536**（2^16）内部单位 = 表现层 1 Godot 米。存储仍是 int64，即 Q48.16 |
| 舍入 | **向零截断**，与 GDScript 整数 `/` 一致 |
| 溢出 | **拒绝该次运算**（不饱和、不回绕成合法值）；乘法用纯 GDScript 的 64×64→128 再除以尺度，避免 `a * b` 先爆 int64 |
| 三角函数 | **4096 项整数查找表**；角度用 BAM（65 536 = 一周）；表项之间用整数线性插值（同样向零截断）。禁止引擎浮点三角函数 |

经济、伤害、耐久：**尺度 1 的 int64 整数**（1 金 = 1，1 点伤害 = 1）。它们仍是「有明确尺度的 64 位整数」，但不共用空间尺度，避免 1 金变成 65 536 这种无法手读的内容数据。

水平朝向与击退方向走 BAM，不走弧度。

## 理由

- **2^16 而不是 1000**：除以尺度是位移，跨 Windows / macOS / Linux 的整数除法没有「十进制好读但要解释余数」的额外口径；1/65536 米 ≈ 0.015 mm，够直立胶囊扫掠，又远小于 int64 空间头寸。
- **2^16 而不是 2^32**：Q32.32 在「两个量相乘再还原」时几乎必然需要 128 位；2^16 对一期赛道尺度更宽裕，widening mul 仍要实现，但合法 UGC 更不容易天天撞上限。
- **向零截断**：零新语义，测试夹具与心算都和 `int / int` 相同；银行家舍入要到出现可观察偏差再单独立项。
- **拒绝而不是饱和**：饱和会把非法 UGC 或 bug 变成「看起来合法的位置/伤害」，回放对得上但玩法错了。拒绝后由调用方生成可定位错误（对齐 Rule VM 超 gas 的处理哲学）。
- **LUT 而不是 CORDIC**：表可审查、可单测、可解释；CORDIC 迭代次数和缩放因子更容易被写错却仍「看起来平滑」。
- **经济尺度 1**：金币与伤害本就是离散计数；硬套空间尺度只折磨 Schema 和创作者，不增加确定性。

表现层换算只允许出现在 `game/src/client/`（以及后续 creator 预览的表现映射）。`shared/` 与 `simulation/` 不得出现该除法的 `float` 形式。

## 备选

**尺度 1000（毫米）**：内容 JSON 可读，编辑器心算方便。代价是除法不是位移，且 1 mm 对高速扫掠偏粗。若更关心手改夹具可读性，可选此项，其余三项仍按推荐。

**饱和溢出**：调试期更不容易炸房，但会掩盖内容错误，不推荐进权威路径。

**最近点 LUT、不插值**：实现更短，4096 项约 0.09°。若拍板希望少一行插值，可以降级；推荐保留整数插值，因为击退方向差 0.09° 会在长距离上被放大。

**运行时调用 `sin()` 再量化**：跨平台浮点与引擎版本都会进哈希，直接否决。

## 不在本 ADR

- Tick / 快照 / 输入频率（CD-63 第 1.5 条）
- 世界边界的具体米数（内容验证预算，未锁定）
- 组件字段清单（已在 CD-42，不在这里复述）

## 选定

**选项 1：整包采纳推荐**（2026-08-21）。所有者文档是 [CD-42 §1.1](../../Confirmed-docs/40-technical/42-contracts-and-rulevm.md)；实现落在 `game/src/shared/fixed/`。

## 落地

1. CD-42 §1.1 写入尺度与规则；CD-63 第 1.6 条迁出；[CD-91](../../Confirmed-docs/90-reference/91-decision-log.md) 留痕；
2. `Fixed` / `FixedResult` / `FixedSinLut` 与 GUT：加、减、乘除、溢出拒绝、BAM 一周、`sin(0)` / `sin(1/4 周)`、插值；
3. 查找表是整数常量，运行时不调用引擎 `sin`/`cos`。
